# 极简番茄钟

当前只维护浏览器扩展，Codex 个人系统插件方案已舍弃。GitHub 仓库为 `JUHUAX/personal-system`；`usable-v1` 分支保存本次界面调整前的可用版 V1（7.1.1），`main` 为后续改进版（7.1.2）。不上传浏览器个人记录、授权和本地设置导出。

## 7.1.2 更新

- 时间块编辑去除轮次、完成度、专注度和打断评级；番茄钟结束后的评价也只填写完成情况。历史结构字段保留，不再展示评级，不修改既有自动完成规则。
- “时间记录 → 灵感记录”为连续草稿本，显示全部已有灵感，不按周拆成每日框。日期分界线位于该日内容之后；当天结束或下次打开时自动分隔，只为有内容的日期插入分界线。当天内容写在末尾，仍复用原每日存储，并与每日时间流中的灵感输入同步。
- 输入自动本地保存；刷新不覆盖草稿，失败保留原文，日期分界线缺失/重复时阻止覆盖；保存队列避免较早的输入覆盖新版本。
- 阶段计划、待办、每日总结/归档及个人节奏的 Notion 入口移入相应内容的右键菜单。菜单仅开放有效 Notion HTTPS 链接，支持 Escape 和键盘菜单键。
- 灵感页隐藏工作统计和周导航，让编辑区直接可见。

验证：`npm test`；安装开发依赖后运行 `npm run test:browser`。浏览器测试使用隔离的虚构记录与模拟扩展接口，不访问真实 Notion/LLM 或浏览器个人数据。测试截图保存在忽略的 `test-results/` 目录。

## Notion + LLM 生产力闭环

- 时间轴“配置”页面可一键检查、复用、升级或创建 Time Record、Phase Plan、Planning Profile、Daily Todo、Daily Review。
- 用户以自然语言制定任意天数的阶段计划，LLM 拆分每日里程碑；每天填写完成情况后生成当日总结和次日定时待办。
- Daily Todo 可以直接启动番茄钟，并把待办 ID、链接和累计投入写入时间记录与 Notion。
- 插件直接调用 LLM API；接口、模型、API Key 和定时时间均可在前端配置，不需要部署 Cloudflare Worker。
- 支持测试连接、同步本周、同步全部以及时间记录变化后的延迟自动同步。
- 只同步已结束的真实记录，不同步正在运行或自动补全的“未记录时间”。
- 待办可在插件中增删改、完成和自然语言重排；LLM 不会脱离阶段计划，也不能自行标记完成。
- 支持按设定时间直接调用 LLM，并将结构化日报新增或更新到 Daily Review。
- LLM 密钥不会写入扩展源码，只保存在当前浏览器的扩展本地存储中。
- 数据库字段、权限和同步规则参见 [NOTION_INTEGRATION.md](./NOTION_INTEGRATION.md)。
- 完整安装、每周/每日流程、Prompt 契约和未决策清单参见 [PRODUCTIVITY_WORKFLOW_README.md](./PRODUCTIVITY_WORKFLOW_README.md)。
- 已确认并实现的阶段计划、个人节奏和时间化待办规则见 [PRODUCT_DECISIONS_V2.md](./PRODUCT_DECISIONS_V2.md)，三类 Prompt 见 [LLM_PROMPTS_V1.md](./LLM_PROMPTS_V1.md)。

现有番茄钟计时、完成判定、评价、离开机制、时间轴和 Dashboard 统计逻辑保持不变。

当前主导航为“番茄钟 / 今日 / 时间记录 / 统计 / 配置”。“今日”同屏展示当天时间块与时间流；“时间记录”内可切换多日时间块、多日时间流和阶段计划数据库。多日时间流按周一至周日展示七张并列日卡，每张卡依次包含待办、真实时间流、用户完成情况和 LLM 当天总结。

阶段计划由 LLM 首次命名并以稳定计划 ID 关联 Daily Todo 和 Daily Review；执行中可用自然语言重排剩余里程碑，名称保持不变。阶段到期后会生成阶段总结并写回 Notion。今日页顶部显示当天里程碑，全部阶段内容收入折叠区；所有计划统一在“时间记录 → 阶段计划”管理。配置页支持默认 10 分钟、可调整间隔的定时双向 Notion 同步。

点击扩展图标会直接打开时间轴主页面，不再显示“打开时间轴 / 打开置顶小窗”的中转选择页。主页面新增“番茄钟”标签，使用与原置顶小窗相同的计时和设置逻辑；点击其中的“打开置顶小窗”可将当前计时界面转移到置顶小窗，关闭后回到主页面继续使用。

## 本版调整

- Notion 单次请求设置 30 秒超时，LLM 单次请求设置 60 秒超时。日内后台调整改为“读取 Notion / LLM 生成 / 自动修正 / 逐条写入 / 完成”分阶段心跳；只有当前阶段长时间没有新心跳时才判定后台任务断联。
- 时间流中的真实记录可直接点击编辑，工作记录只填写完成情况。
- 番茄钟模式与四项时长会保存在本机；“单独工作”到时后结束，只有“连续工作”会自动开始下一个番茄。
- 待办、阶段计划、完成情况、当天总结和每日归档采用本地缓存优先显示，再在后台向 Notion 刷新；网络刷新失败时保留上次可用数据。
- 高频手工修改改为“本地先响应”：待办的新增、编辑、状态、删除，完成情况与个人节奏会立即更新界面，随后按配置的同步间隔批量写入 Notion。同一条数据的连续修改会合并，未同步的本地新建待办如果又被删除，不会产生多余 Notion 请求。
- 页面顶部的“N 项待同步”会显示队列状态，点击可立即写入；写入失败的操作会保留并在下次同步重试。LLM 生成、调整和每日总结仍作为完整事务直接写入 Notion，并会先提交本地待同步数据。
- 新增一级“今日”工作台，同屏展示当天的真实/计划时间块与完整时间流卡片；原“时间块”和“时间流”合并到二级“时间记录”页，通过页内按钮切换多日视图。
- “今日”页顶部的阶段计划只直接展示当天里程碑，整个阶段的每日计划、原始描述、调整记录和阶段总结收入“查看全部阶段计划”折叠区。
- “时间记录”新增“阶段计划”二级页，以卡片展示 Notion 中的全部 Phase Plan，支持新增、查看详情、编辑基本信息和删除。删除时计划页面会移入 Notion 回收站，关联待办、日报和归档会解除绑定。多日时间块与时间流不再重复展示阶段计划。
- 时间流页取消 1580px 最大页面宽度，日卡会随浏览器宽度自动切换为约 4 / 3 / 2 / 1 张可见，其余日期继续通过底部滚动条查看。
- LLM 待办调整改为显式删除协议：模型必须返回 `deletedTodoIds`，省略待办不再触发归档；应用旧预览前会校验 Notion 最后编辑时间。
- LLM 待办调整现在只保护 `done`；手工创建、进行中和原时间已过但未完成的待办均可重排。过时待办必须移到本次调整起点之后或被显式删除，不会再被错误保护在过去。
- “自动生成每日总结”和“13:00/18:00 自动调整日内待办”拆分为两个独立开关。
- 阶段计划的生成与调整表单改为按需弹窗；主卡片只保留“生成阶段计划”或“调整阶段计划”。调整可选普通重排、延长时间或提前结束。
- 阶段调整说明可留空；提前结束允许选择昨天等过去日期，会直接截断计划并同步 Notion，不调用 LLM。
- 计划最后一天可手动生成阶段总结；提前结束后会询问是否立即生成。总结会综合每日待办状态、完成情况、真实时间投入和按日统计，并写回 Notion Phase Plan。
- 首日待办手动或后台生成时均从触发时间至少 10 分钟后开始，不再回填已经过去的全天计划。
- 阶段计划第一天在没有前一日待办、完成情况或总结时，可以直接根据首日里程碑和个人节奏生成当天待办；此分支不生成虚假的前一日日报，前端按钮和后台定时任务均适用。
- 创建以当天为首日的阶段计划时，插件会紧接着生成首日待办；每日 00:05 的后台检查会为预先创建的计划补生成首日待办。
- 当日总结与次日待办改为独立落库：次日没有阶段计划、里程碑或工作窗口时，仍保留当日总结和归档，只跳过次日待办。
- 删除本地时间块会建立同步删除标记：Notion 拉取会阻止记录复活，下一次推送会把对应 Notion 时间记录移入回收站并清理映射。
- 阶段计划拆分、阶段调整、待办 LLM 调整和每日总结生成时，按钮会持续显示“生成中 · N 秒”，状态栏同步显示通常耗时范围和已等待时间。
- 今日阶段计划、时间流待办、已生成的当天总结和阶段计划数据库卡片的 Notion 入口在右键菜单中；仅在确有有效页面链接时显示。
- 完成情况允许保存空文本，用于清空并覆盖 Notion Daily Review 中原有内容。
- 时间流日卡片加宽为视口内约显示四张，其余三张通过底部横向滚动条查看，并增加清晰的选中边框。
- 今日阶段计划卡以 LLM 拆分的当天目标、任务估时、可交付物和说明为主体；用户原始描述、约束、全部里程碑和阶段总结默认收起。
- “未记录时间”自动补全改为时间块页面的纯视觉数据：不写入本地记录、不显示在时间流、不参与统计和 Notion 同步；旧版已落盘的自动补全记录会自动清理。
- 时间块工具栏新增“补全空白”开关，可随时控制是否显示虚拟补全块，选择会保存在当前浏览器中。
- 修复删除待办后，后台仍根据历史时间记录更新该待办累计投入而触发“Can't edit block that is archived”错误的问题；已进入 Notion 回收站的对象会被安全跳过。
- 修复 Notion API 2026-03-11 下删除待办报错的问题；删除会同步将对应 Notion 页面移入回收站。
- 保存或删除待办、保存或删除时间块后，对应编辑弹窗会自动关闭。
- 弹窗仅在鼠标按下与释放都发生在遮罩空白处时关闭，拖动选择文字到弹窗外再释放不会误关闭。
- 配置页下半区改为稳定的双列网格，避免移除重复卡片后内容全部挤在左侧。
- 配置页不再展示“每日待办”和“完成情况与每日生成”两张重复卡片；相关操作统一在“时间流”的每日卡片中完成。
- 置顶小窗顶部任务名称改为只读展示：从待办启动时直接使用待办名称，不再提供手动填写、历史候选或默认标题催填功能。
- 未从待办启动的普通番茄钟统一以“工作”记录，不再弹出任务标题输入流程。
- 自动补全“未记录时间”仅作用于每天第一条真实记录开始到最后一条真实记录结束之间。
- 第一条记录之前、最后一条记录之后不再补全。
- 每天少于两条有效记录时，不生成自动补全块。
- 仍限制在 09:00-22:00 范围内。

## 延续 v64 新增与调整

- 点击“离开”后暂停番茄钟，不立即结束当前番茄钟，也不立即询问离开理由。
- 用户点击原播放/继续按钮即表示归来，此时弹窗询问离开理由。
- 10分钟内归来：继续原番茄钟剩余时间，不新增生活时间块。
- 短暂离开会作为结构化打断信息保存在当前工作记录中，并显示在文字模式和悬浮卡片中。
- 超过10分钟：后台只标记为长时间离开，不会自动启动新番茄钟。
- 用户归来点击继续后，旧番茄钟结束于离开开始时间，创建生活类型离开时间块，并启动全新完整番茄钟。
- 正常时段内离开记录最多记到当天22:00；09:00-22:00之外开始离开时，最长只记录1小时。
- 关闭插件时若仍处于长时间离开，会按照相同边界规则收尾，避免生成超长记录。

## 安装

1. 解压 `minimal_pomodoro_extension_v8.zip`
2. 打开 Edge：`edge://extensions/`
3. 打开开发人员模式
4. 点击“加载解压缩的扩展”
5. 选择解压后的 `minimal_pomodoro_extension_v8` 文件夹
6. 点击扩展图标
7. 在控制页点击“打开置顶小窗”
